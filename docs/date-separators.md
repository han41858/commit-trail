# 월·일 날짜 구분선

날짜 구분선은 DAG의 시간 흐름을 읽기 위한 보조 표현이다. 일반 화면과 Split view, Older·Newer에서 같은 기준을 사용한다. 커밋의 위상 순서·레인·31px 행 간격·스크롤·API 조회는 바꾸지 않는다.

## 날짜와 레이블

- 유효한 커미터 시각을 우선하고, 없으면 유효한 작성자 시각을 사용한다. 둘 다 없으면 제외한다.
- 브라우저 현지 시간대의 연·월·일로 그룹을 정한다. Locale은 표시 형식에만 영향을 준다.
- 월 경계는 `Intl.DateTimeFormat(undefined, { dateStyle: 'short' })`로 앵커의 실제 전체 날짜를 표시한다. 앵커는 반드시 매월 1일에 있는 것이 아니다.
- 일 경계는 `Intl.DateTimeFormat(undefined, { day: 'numeric' })`로 일자만 표시한다. 숫자를 두 자리로 고정하거나 구두점을 직접 조합하지 않는다.

## 경계 확인과 앵커

1. 기준 브랜치의 조회된 first-parent 이력에 등장하는 월과 날짜를 경계 확인에 사용한다. 해당 경로가 아직 로딩되지 않은 창에서는 기존처럼 조회된 이력을 사용한다.
2. 가장 오래된 부분 월과 날짜는 각각 더 오래된 기준 이력이 확인되기 전까지 유예한다. 알려진 root가 시작을 확인하는 경우에는 저장소가 월·일 중간에 시작해도 표시한다. 무관한 오래된 분기는 기준 이력의 부분 경계를 확정하지 않는다.
3. 확인된 각 월과 날짜에서 **로딩된 전체 커밋 중 시각이 가장 이른 커밋**을 앵커로 선택한다. 다른 레인의 커밋도 후보이며 시각이 같으면 SHA로 결정한다.
4. 추가 이력에서 더 이른 후보가 발견되면 앵커를 옮긴다. 월과 날짜의 확인은 독립적이므로 일 경계가 월 경계를 새로 확정하거나 위치를 바꾸지 않는다.
5. 같은 SHA에 월·일 앵커가 있으면 월만 표시한다. 다른 SHA의 일 앵커는 유지한다. 일자가 `1`인지로 중복을 판정하지 않는다.

같은 날짜의 구분선은 최대 하나이며, 커밋 없는 날짜는 생성하지 않는다. DAG는 날짜순 목록이 아니므로 인접한 커밋의 날짜가 바뀔 때마다 선을 만들지 않는다. 시각 역전이 있어도 정렬을 바꾸지 않고 대표 앵커를 사용한다.

## Canvas 표시

- 월 레이블은 기존 11px, 일 레이블은 10px로 표시한다. 월 선·글자를 더 뚜렷하게 하고 일 선·글자의 불투명도는 낮춘다.
- 선은 현재 그래프의 가시 너비를 가로지르고 레이블은 오른쪽에 정렬한다. 기존 테마의 `--month-line`, `--muted`, `--bg`를 사용해 라이트·다크 모두 같은 위계를 적용한다.
- 실제 문자열을 측정해 레이블 배경을 그린다. 좁은 열에서는 Canvas의 `maxWidth`로 문자열 전체의 표시 폭을 줄여 글자나 배경이 열 밖으로 잘리지 않게 한다. 날짜 구성 요소를 생략하지 않는다.
- 레이블은 기존처럼 선 바로 위에 놓고 배경 높이 15px를 사용해 연속된 31px 행에서도 날짜 레이블끼리 겹치지 않는다. 그래프 콘텐츠보다 먼저 그려 기존 노드·메시지·입력 판정을 유지한다.
- 설정·저장 키·애니메이션·Hover·클릭 동작을 추가하지 않는다.

## 구현 위치

`src/graph/dateMarkers.ts`가 월·일의 공통 경계 확인과 Locale 레이블을 계산한다. `src/graph/monthMarkers.ts`의 기존 월별 API와 회귀 테스트도 같은 앵커 계산을 사용한다. 날짜 포매터는 재사용하고 `Graph.tsx`에서 마커를 메모하므로 Hover 애니메이션 프레임마다 포매터를 만들거나 날짜 그룹을 다시 계산하지 않는다. `graphCanvas.ts`는 계산된 마커의 유형에 맞춰 그리기만 담당한다.
