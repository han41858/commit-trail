# 월·일 날짜 구분선

날짜 구분선은 DAG의 시간 흐름을 읽기 위한 보조 표현이다. 일반 화면과 Split view, Older·Newer에서 같은 기준을 사용한다. 커밋의 위상 순서·레인·31px 행 간격·스크롤·API 조회는 바꾸지 않는다.

## 날짜와 레이블

- `commitTime()`은 유효한 커미터 시각을 우선하고, 없거나 잘못됐으면 유효한 작성자 시각을 사용한다.
  유효한 시각이 없는 커밋은 날짜 구분선 계산에서 제외한다.
- 브라우저 현지 시간대의 연·월·일로 그룹을 정한다. 로캘은 표시 형식에만 영향을 준다.
- 월 경계는 `Intl.DateTimeFormat(undefined, { year: 'numeric', month: 'long', day: 'numeric' })`로 앵커의 실제 전체 날짜를 표시한다. 한국어에서는 `2026년 11월 3일`처럼 일 경계의 `4일`과 같은 지역 표기 관례를 따른다. 앵커는 반드시 매월 1일에 있는 것이 아니다.
- 일 경계는 `Intl.DateTimeFormat(undefined, { day: 'numeric' })`로 일자만 표시한다. 숫자를 두 자리로 고정하거나 구두점을 직접 조합하지 않는다.

## 경계 확인과 앵커

1. 기준 브랜치에서 조회한 첫 번째 부모 이력의 가장 오래된 월과 날짜를 각각 부분 로딩의 하한으로 사용한다.
   기준 경로의 커밋이 하나도 로딩되지 않았으면 조회한 전체 이력을 기준으로 삼는다.
   각 하한보다 새로운 월·날짜는 조회한 전체 커밋에 존재하면 표시한다. 기준 이력에 없는 분기 작업일이나 더 최신 날짜·새 달도 포함한다.
   예를 들어 `main`이 11월에 있어도 `dev`에만 12월 커밋이 있으면 그중 시각이 가장 이른 조회 커밋에 월 레이블을 표시한다.
2. 가장 오래된 월과 날짜의 구분선은 각각 더 오래된 기준 이력이 확인되기 전까지 유예한다.
   단, 해당 월·일의 기준 이력에서 시각이 가장 이른 커밋이 부모 없는 루트라면 월·일 중간에 시작해도 구분선을 표시한다.
   기준 이력에서 가장 이른 시각이 같으면 시작 확인에는 루트를 우선한다. 이 우선순위는 대표 앵커 선택에는 적용하지 않는다.
   각 하한보다 오래된 무관한 분기는 해당 월·일 경계를 만들거나 부분 경계를 확정하지 않는다.
3. 확인된 각 월과 날짜에서 **로딩된 전체 커밋 중 시각이 가장 이른 커밋**을 앵커로 선택한다. 다른 레인의 커밋도 후보이며 시각이 같으면 SHA로 결정한다.
4. 추가 이력에서 더 이른 후보가 발견되면 앵커를 옮긴다. 월과 날짜의 확인은 독립적이므로 일 경계가 월 경계를 새로 확정하거나 위치를 바꾸지 않는다.
5. 같은 SHA에 월·일 앵커가 있으면 월만 표시한다. 다른 SHA의 일 앵커는 유지한다. 일자가 `1`인지로 중복을 판정하지 않는다.

같은 날짜의 구분선은 최대 하나이며, 커밋 없는 날짜는 생성하지 않는다. DAG는 날짜순 목록이 아니므로 인접한 커밋의 날짜가 바뀔 때마다 선을 만들지 않는다. 시각 역전이 있어도 정렬을 바꾸지 않고 대표 앵커를 사용한다.

## Canvas 표시

- 월 레이블은 기존 11px, 일 레이블은 10px로 표시한다. 월 선·글자를 더 뚜렷하게 하고 일 선·글자의 불투명도는 낮춘다.
- 선은 현재 그래프의 가시 너비를 가로지르고 레이블은 각 그래프의 왼쪽 가시 가장자리에서 4px 안쪽에 정렬한다. 배경의 좌우 여백은 3px이며 아주 좁은 열은 여백도 줄인다. 기존 테마의 `--month-line`, `--muted`, `--bg`를 사용해 라이트·다크 모두 같은 위계를 적용한다.
- 실제 문자열을 측정해 레이블 배경을 그린다. 메시지가 보이면 레이블과 배경을 메시지 열 왼쪽으로 제한하고, 메시지가 숨겨진 열은 가시 너비를 사용한다.
  좁은 영역에서는 날짜 구성 요소를 생략하지 않고 Canvas의 `maxWidth`로 문자열 전체의 표시 폭을 줄인다.
  가로 스크롤로 메시지 열만 남아 공간이 없으면 레이블 전체를 생략하고 선은 유지한다.
- 레이블의 Canvas bottom 기준점을 구분선 행의 1px 아래에 두어 실제 글자 하단이 선에 가깝게 붙도록 한다. 배경 높이는 15px이며 아래쪽은 구분선 행의 2px 아래에 놓는다. 연속된 31px 행에서도 날짜 레이블끼리 겹치지 않는다. 그래프 콘텐츠보다 먼저 그려 기존 노드·메시지·입력 판정을 유지한다.
- 설정·저장 키·애니메이션·Hover·클릭 동작을 추가하지 않는다.

## 구현 위치

`src/graph/dateMarkers.ts`는 월·일의 공통 경계를 확인하고 로캘에 맞는 레이블을 계산한다. `src/graph/monthMarkers.ts`의 기존 월별 API와 회귀 테스트도 같은 앵커 계산을 사용한다. 날짜 포매터는 재사용하고 `Graph.tsx`에서 마커를 메모하므로 Hover 애니메이션 프레임마다 포매터를 만들거나 날짜 그룹을 다시 계산하지 않는다. `graphCanvas.ts`는 계산된 마커의 유형에 맞춰 그리기만 담당한다.
