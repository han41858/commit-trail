# Commit Trail 문서 안내

문서는 현재 `dev` 구현을 기준으로 관리한다. 과거 검증 기록과 스크린샷은 촬영 당시 환경의 결과로 해석한다.

## 기본 안내

- [제품 명세](specification.md)는 현재 기능과 공통 제약, 제품 검증 범위를 요약한다.
- [개발·운영 가이드](technical-guide.md)는 기본 사용법, 코드 구조, 개발 환경, CI, AI 작업 재개, Vercel 배포와 릴리즈 절차를 안내한다.
- [스크린샷 안내](images/README.md)는 촬영 시점과 조건, 재현 방법을 기록한다. 제품 소개와 실제 이미지는 [프로젝트 README](../README.md)에서 확인한다.
- 개발·검증·커밋·PR·머지·배포 절차는 [개발 지침](../AGENTS.md)을 따른다.

## 기능별 상세 명세

- [경로 색상과 하이라이트](dag-hover-highlight.md)는 경로 소유권, 색상 재현 조건과 입력 동작을 설명한다.
- [날짜 구분선](date-separators.md)은 월·일 경계와 라벨 배치 기준을 설명한다.
- [자동 갱신·메타데이터](auto-refresh-and-metadata.md)는 갱신·오류 처리와 태그·릴리즈·Actions 표시를 설명한다.
- [Split view](monitor-mode.md)는 저장소 선택·정렬·공유와 분할 화면의 동작을 설명한다.
- [Owner 저장소 선택](owner-repositories.md)은 공개·인증 목록 조회와 페이지 처리를 설명한다.
- [최근 저장소](recent-repositories.md)는 방문 이력·브랜치 선택 기록과 PAT 변경 시 처리를 설명한다.
- [PWA](pwa.md)는 설치, 앱 셸 캐시, 업데이트와 장애 복구를 설명한다.
- [개발자 진단](developer-debug-mode.md)은 진단 활성화 방법과 측정 범위·해석 한계를 설명한다.

세부 규칙은 전용 명세에서 관리한다. 동작을 바꾸면 관련 명세의 수치·예외·링크를 함께 확인하고, 현재 동작과 과거 검증 결과를 구분한다.
설명이 충돌하면 구현과 확정된 요구사항을 대조한다.
